# Python & AI駆動開発 学習ログ

## 学習者プロフィール
- COBOL / FORTRAN 実務経験（約30年前）
- 自治体システム開発 30年以上、現在は開発マネージャ兼コンサルタント
- Python は初心者
- 目標: Python基礎を固めつつ、AI駆動開発（Claude Codeのようなツールを使った開発）の考え方を基礎から学ぶ

## 進め方
1. コードを書く前に「なぜそう設計するのか」を説明する
2. 小さく動くものを一緒に作る（ペアプログラミング形式）
3. COBOL/FORTRANでの経験と対比させながら理解を進める
4. ある程度Pythonに慣れたら、AI駆動開発（要件→AIへの指示→レビュー→反復）の実践に進む
